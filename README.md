# A/B-тест формы оплаты ЖКХ

Оценка эффективности новой формы оплаты с автозаполнением реквизитов.

### Задача
- **Гипотеза:** Новая форма увеличит конверсию в успешную оплату
- **Метрика:** Конверсия из открытия формы (шаг 1) в успешную оплату (шаг 4) **на уровне пользователя**
- **Период:** 1-30 апреля 2024

### Решение
1. **EDA и очистка:** исключены аномалии (пропуски, выбросы, несогласованность групп)
2. **Валидация теста:** проверка на SRM (Sample Ratio Mismatch) и однородность групп по возрасту, городу и типу устройства
3. **Воронка и unit of analysis:** расчет конверсии на уровне пользователя из-за множественных попыток оплаты для сохранения независимости; **дополнительно**: расчет конверсии по первой попытке
4. **Статистика:** z-тест для пропорций (проверка через $\chi^2$), расчет MDE и доверительного интервала
5. **Анализ стабильности:** проверка на эффект новизны (динамика по неделям) и сегментный анализ

### Результаты
- Конверсия в контроле (A): **65.7%**
- Конверсия в тесте (B): **80.4%**
- Прирост: **+14.7 п.п.** (относительный рост +22.4%)
- **p-value < 0.001** (эффект статистически значим), 95% ДИ [10.3; 19.1] п.п.
- Эффект превышает MDE (**6.9 п.п.**)
- Эффект стабилен во времени и наблюдается во всех ключевых сегментах

### Бизнес-вывод
Новая форма дает статистически и практически значимый прирост успешных оплат.
